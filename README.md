# Marca personal — Patricia García Becerra

Sitio web estático, responsive y en español, elaborado a partir de la hoja de vida suministrada.

## Contenido
- `index.html`: estructura y contenido del sitio.
- `styles.css`: identidad visual, diseño adaptable y animaciones.
- `script.js`: menú móvil, año automático y aparición progresiva de secciones.

## Ver el sitio en tu computador
Abre `index.html` en un navegador. Para una experiencia más cercana al alojamiento, puedes usar la extensión Live Server de Visual Studio Code.

## Publicarlo en GitHub Pages
1. Crea un repositorio nuevo en GitHub, por ejemplo `marca-personal`.
2. Sube `index.html`, `styles.css`, `script.js` y este `README.md` a la raíz del repositorio.
3. En el repositorio, entra a **Settings → Pages**.
4. En **Build and deployment**, selecciona **Deploy from a branch**.
5. Selecciona la rama `main` y la carpeta `/(root)`, y guarda.
6. Espera a que GitHub Pages publique el sitio y usa la URL que aparezca en esa sección.

## Personalización
- Cambia los colores desde las variables CSS al inicio de `styles.css`.
- Edita los textos directamente en `index.html`.
- Los correos se mantienen porque la solicitud fue excluir dirección física y teléfonos. Se omitieron también los teléfonos de las referencias personales.
